# Backend MVP

The backend is responsible for:

- Authentication
- Marketplace APIs
- Agent Registry
- Agent Execution
- Payment Router
- Trust Engine
- Wallet Integration
- Algorand Integration
- OpenRouter Integration
- Database
- Analytics

The backend must expose REST APIs.

Frontend should never directly communicate with blockchain.

All blockchain interactions happen through backend services.

All AI execution happens through backend.

The backend must remain modular and scalable.
